# 📊 Week 2: Sorting Foundations

This folder contains my implementations of the 5 core sorting algorithms. My goal was to move from $O(N^2)$ simple sorts to $O(N \log N)$ advanced "Divide & Conquer" strategies.

## 🚀 Algorithms Implemented


| Algorithm | Best Case | Worst Case | Space | Stability |
| :--- | :--- | :--- | :--- | :--- |
| **Selection Sort** | $O(N^2)$ | $O(N^2)$ | $O(1)$ | Unstable |
| **Bubble Sort** | $O(N)$ | $O(N^2)$ | $O(1)$ | Stable |
| **Insertion Sort** | $O(N)$ | $O(N^2)$ | $O(1)$ | Stable |
| **Merge Sort** | $O(N \log N)$ | $O(N \log N)$ | $O(N)$ | Stable |
| **Quick Sort** | $O(N \log N)$ | $O(N^2)$ | $O(\log N)$ | Unstable |

## 💡 Key Learnings
- **The Pivot Wall:** Mastered the partitioning logic in Quick Sort to achieve in-place sorting.
- **Divide & Conquer:** Understood how recursion breaks down large problems (Merge Sort).
- **Stability:** Learned why preserving the order of equal elements matters in real-world data (e.g., e-commerce orders).
- **In-Place Sorting:** Optimized memory by sorting within the original array boundaries.
